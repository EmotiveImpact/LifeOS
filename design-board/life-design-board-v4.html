01 · Evolution

Keep the ideas. Rebuild the surface.

What carries over from v1–v3, what gets reworked so it stops echoing the references, and what goes.

Keep, because it's ours

  • Talk → File → Know → Ask → Nudge → Rise. The product loop.
  • Two-tone sentences. Now Inter 500 with tight tracking.
  • Ticks as the only progress style.
  • The dotted orb as the brand mark.
  • Instruments (pulse, count, attach), never forms.
  • Levels as vantage points.

Evolve, so it stops echoing

  • Photo atmospheres become light fields: a soft domain-coloured glow over a faint dot grid.
  • Pill buttons become 14px-radius slabs. Pills stay for tags only.
  • "No borders" becomes hairline depth: 1px light edges define surfaces.
  • Big rounded cards become 20px cards with 12px tiles. Tighter and more precise.
  • Circle checks become 7px-radius squares, like a real checklist.
  • Island stays, as a quiet status. No globe theatrics.

Drop

  • Instrument Serif. Inter only, with display weights for numbers.
  • Warm stone paper. Light mode is now a cool, neutral white.
  • Stock-photo cards and full-bleed sunsets.
  • Reference layouts 1:1 (the ledger, subscribe screen, check-in).
  • Decorative gradients on cards. Glow lives in one place per screen.
02 · Type

Inter, set tight and confident.

One family carries everything. Optical sizing switches to the Display cut at large sizes. Big type gets negative tracking, numbers use tabular figures, and weight does the work the serif used to.
